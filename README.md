# Bahrain Reviews Sentiment Analysis App

This project is a web application designed to analyze customer feedback for businesses in Bahrain. It leverages advanced Natural Language Processing (NLP) models to classify sentiment in real-time.

## 🚀 Live Application
Access the live app here: 
👉 [https://textclassification1.streamlit.app/](https://textclassification1.streamlit.app/)

## 📝 Project Overview
This application uses the `cardiffnlp/twitter-roberta-base-sentiment-latest` model to provide accurate sentiment analysis for user reviews. It is built to help businesses understand customer satisfaction levels quickly and efficiently.

## 🛠️ Tech Stack
* **Framework:** Streamlit
* **AI/ML:** Hugging Face Transformers (RoBERTa)
* **Language:** Python
